# Decision Rank Lab

공개 사이트: https://decision-rank-lab.pages.dev/

지진으로 학교 4층 교실에 고립된 가상 상황에서 12개 물품의 개인·모둠 순위를 정하고 PPT의 고정 수업 기준과 비교하는 한국어 웹 도구입니다.

## 기능

- 순위 선택 및 위·아래 이동 버튼. 순위는 항상 중복 없는 1~12위입니다.
- 개인·모둠 순위, 물품별 근거, 활동 상황, 별칭 및 후기 기록.
- 추가 PPT 2쪽의 시나리오를 순위 입력 화면에서 함께 확인합니다. 넓은 PC 화면에서는 순위 옆에 시나리오가 고정되고, 모바일에서는 요약과 펼치기로 읽습니다.
- 별도 기준·교사용 메뉴 없이 결과 비교 화면에서 9쪽의 고정 기준, 순위의 판단 흐름과 12개 물품별 이유를 봅니다. 비교 표의 ‘이유 보기’는 해당 설명을 펼칩니다.
- 시작 배열은 개인·모둠별로 무작위이며, 원본 목록 순서가 답안으로 노출되지 않도록 물품 번호 표시는 제거했습니다.
- 7쪽의 S~D 구간과 등급별 확률 수치를 표시합니다. 명칭은 ‘생존 확률(실제 생존 확률이랑 다를 수 있음)’이며, 검증된 재난 예측값이 아닌 흥미 요소입니다.
- 개인·모둠 오차 차이에 따라 사용자가 제공한 ‘집단지성의 성공 / 집단 동조 현상 / 토론의 부재 또는 확신’을 수업자료의 해석으로 표시합니다. 물품별 오차 감소·증가·동일 개수와 합계가 같아도 순위가 달라진 경우를 함께 보여줍니다.
- 물품별 절대 순위 오차, 오차 합계, 환산 점수, 모둠 개선량.
- 브라우저 저장 선택, 활동 JSON 내보내기/불러오기, CSV 결과, 인쇄/PDF.
- 모바일·PC·키보드 조작, 사이트 내 이용 가이드·FAQ·소개·데이터 안내.

## 계산

물품별 오차 = |입력 순위 − 고정 기준 순위|. 오차 합계는 0~72점이며 낮을수록 자료 기준과 유사합니다. 환산 점수 = (1 − 합계/72) × 100 (소수 첫째 자리). 모둠 개선량 = 개인 오차 − 모둠 오차. 개인·모둠 순위를 확정하면 자동 계산하며 수정하면 해당 확정이 풀립니다.

고정 기준: 분말 소화기 → 구급상자 → 롱패딩과 담요 → 정수기 10L 생수통 → 대형 비닐 쓰레기봉투 → 커터칼 → 모의고사 시험지 뭉치 → 건전지형 라디오 → 스마트폰 및 보조배터리 → 고열량 에너지바 1박스 → 라이터 → 고카페인 에너지 드링크.

등급: S 0~12, A 14~26, B 28~42, C 44~56, D 58~72. 연결된 확률 표시는 각각 99% 이상, 80~90%, 40~60%, 10~20%, 0%입니다. 같은 등급 안에서는 오차가 줄어도 확률 표시는 같습니다. 오차 합계는 항상 짝수입니다. 자료 6쪽의 판단 요소와 8쪽의 토론 비교는 설명·성찰 질문으로 반영했습니다. 점수만으로 실제 생존 가능성이나 토론의 원인을 단정하지 않습니다.

자료의 ‘48시간’은 수업 가정입니다. 소화기·비닐·카페인 관련 단정적 설명은 수업 근거와 안전 보충을 구분했으며 사이트에서 USFA, NHS, NIH 원문 링크를 제공합니다. 원본 PPT 및 이미지는 공개 저장소에 업로드하지 않았습니다.

## 로컬 실행

Node.js 22 이상에서 `npm test`, `npm run dev`를 실행하고 http://127.0.0.1:4173 에 접속합니다. 외부 패키지 설치가 필요 없습니다. 간단한 오프라인 사용은 `dist/index.html`을 열어도 가능합니다. 파일 직접 열기에서는 브라우저별 자동 저장 지원이 다를 수 있습니다.

## Cloudflare Pages Git 배포 설정

- 유형: **Pages**, GitHub 저장소 연결
- Production branch: `main`
- Framework preset: `None`
- Root directory: 저장소 루트 (비워 둠)
- Build command: `npm run build`
- Build output directory: `dist`
- 환경 변수: `NODE_VERSION=22`
- `main` 푸시 자동 배포 활성화

`dist`는 이미 완성된 정적 사이트입니다. build 명령은 계산 검증을 실행하며 출력 폴더를 다시 생성하지 않습니다. 별도 API 키나 서버·데이터베이스가 필요 없습니다. `_headers`로 보안 헤더를 적용하며 `404.html`은 존재하지 않는 경로를 처리합니다.

## 구조

`dist/index.html`: 순위·시나리오·결과 설명·도움말, `dist/style.css`: 반응형·인쇄 스타일, `dist/core.js`: 고정 자료·점수·오차 변화·파일 검증, `dist/app.js`: 상호작용·수업자료 해석·저장·내보내기. `tests/core.test.cjs`: 계산 경계, 고정 기준, 무작위 배열, 이전 파일 이전, CSV, 오차 비교 검증. `server.cjs`: 로컬 미리보기 전용.

## 데이터와 제한

입력은 브라우저에서 처리됩니다. 자동 저장은 기본 꺼짐이며 선택 시 localStorage에 저장합니다. 실시간 공동 편집, 학급 수집, 교사 인증, 기준 답안 접근 제어는 없습니다. 고정 기준은 공개되어 있으며 편집 방지는 비밀 답안 보호 기능이 아닙니다. JSON에는 기준 스냅샷을 포함하지만 불러올 때는 항상 사이트 기준을 적용합니다. 공개 Issues에 개인정보나 학생 활동 파일을 올리지 마세요. 입력 데이터는 GitHub 저장소에 업로드하지 않습니다.

활동 파일은 버전 2를 사용합니다. 이전 버전 1 파일과 브라우저 저장본의 개인·모둠 순위, 확정 상태, 근거·후기를 유지하고 기존 상황 텍스트는 활동 메모로 옮깁니다. 임의 기준은 새 고정 기준으로 대체됩니다.
