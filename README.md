# Decision Rank Lab

과학적 의사결정 수업의 12개 생존 물품에 대해 개인·모둠 순위를 정하고 교사가 입력한 기준과 비교하는 한국어 웹 도구입니다.

## 기능

- 순위 선택 및 위·아래 이동 버튼. 순위는 항상 중복 없는 1~12위입니다.
- 개인·모둠 순위, 물품별 근거, 활동 상황, 별칭 및 후기 기록.
- 교사 기준 직접 입력. 전문가 정답을 제공하지 않으며 예시는 임의 데이터로 표시합니다.
- 물품별 절대 순위 오차, 오차 합계, 환산 점수, 모둠 개선량.
- 브라우저 저장 선택, 활동 JSON 내보내기/불러오기, CSV 결과, 인쇄/PDF.
- 모바일·PC·키보드 조작, 사이트 내 이용 가이드·FAQ·소개·데이터 안내.

## 계산

물품별 오차 = |입력 순위 − 기준 순위|. 오차 합계는 0~72점이며 낮을수록 입력 기준과 유사합니다. 환산 점수 = (1 − 합계/72) × 100 (소수 첫째 자리). 모둠 개선량 = 개인 오차 − 모둠 오차. 기준 및 해당 순위를 확정한 뒤 계산합니다. 수정하면 확정이 해제됩니다.

## 로컬 실행

Node.js 22 이상에서 `npm test`, `npm run dev`를 실행하고 http://127.0.0.1:4173 에 접속합니다. 외부 패키지 설치가 필요 없습니다. 간단한 오프라인 사용은 `dist/index.html`을 열어도 가능합니다. 파일 직접 열기에서는 브라우저별 자동 저장 지원이 다를 수 있습니다.

## Cloudflare Pages Git 배포 설정

- 유형: **Pages**, GitHub 저장소 연결
- Production branch: `main`
- Framework preset: `None`
- Root directory: 저장소 루트 (비워 둠)
- Build command: `npm run build`
- Build output directory: `dist`
- 환경 변수: `NODE_VERSION=22`
- `main` 푸시 자동 배포 활성화

`dist`는 이미 완성된 정적 사이트입니다. build 명령은 계산 검증을 실행하며 출력 폴더를 다시 생성하지 않습니다. 별도 API 키나 서버·데이터베이스가 필요 없습니다. `_headers`로 보안 헤더를 적용하며 `404.html`은 존재하지 않는 경로를 처리합니다.

## 구조

`dist/index.html`: 화면·도움말, `dist/style.css`: 반응형·인쇄 스타일, `dist/core.js`: 계산·검증, `dist/app.js`: 상호작용·저장·내보내기. `tests/core.test.cjs`: 계산 경계와 잘못된 파일, CSV 보안 검증. `server.cjs`: 로컬 미리보기 전용.

## 데이터와 제한

입력은 브라우저에서 처리됩니다. 자동 저장은 기본 꺼짐이며 선택 시 localStorage에 저장합니다. 실시간 공동 편집, 학급 수집, 교사 인증, 기준 답안 접근 제어는 없습니다. JSON에는 기준 순위도 포함됩니다. 공개 Issues에 개인정보나 학생 활동 파일을 올리지 마세요. 입력 데이터는 GitHub 저장소에 업로드하지 않습니다.
